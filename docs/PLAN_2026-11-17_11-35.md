# Lapisan Platform Mobile (skill mobile-native) — 2026-11-17

## Tujuan

Menjalankan skill `mobile-native` pada seluruh aplikasi: menghapus sisa-sisa
"ini situs di peramban" pada lapisan platform (viewport, sentuh, gulir, safe
area, chrome peramban) tanpa menyentuh desain — dunia "Daftar Kerja Seluler"
di `DESIGN.md` tetap sumber gaya.

## Keputusan

- **Baseline yang sudah ada tidak diubah ulang**: `viewport-fit=cover`,
  token `--safe-top/--safe-bottom` terpakai di bar/tabbar/sheet/canvas,
  `100dvh` pada app shell, input 16px pada layar kecil, `overscroll-behavior-y:
  contain` pada area gulir, tanpa `maximum-scale`/`user-scalable=no`.
- **Hover digerbangi kapabilitas, bukan dihapus.** `(hover: hover) and
  (pointer: fine)` membungkus 4 aturan `:hover` CSS (btn-primary, btn-secondary,
  app-nav-link, prose link). Tailwind v4 `hover:` di TSX sudah tergate bawaan —
  tidak disentuh.
- **Umpan balik tekan global via `:active`, bukan per-instance.** Skala 0.97
  pada `.ui-btn-primary/.ui-btn-secondary` (mengikuti pola `.app-pressable`
  yang sudah ada). Utilitas `active:` per pemanggilan tidak ditambahkan agar
  tidak ada dua konvensi.
- **`user-select: none` hanya pada kontrol** (`button`, `[role='button']`) —
  nomor pengajuan, alamat materi, dan pesan galat tetap bisa disalin.
- **Tidak ada `touch-action: pan-*` tambahan**: tidak ada carousel JS; tabel
  admin menggulir pakai scroll native (`overflow-x-auto`), dan semua `input`
  sudah membawa `ui-control` sehingga tanpa geser kustom.
- **`theme-color` tetap satu nilai `#ffffff`** (sengaja, keputusan audit
  2026-10-01: aplikasi belum punya dark mode) — tapi manifest PWA
  `theme_color` diselaraskan dari `#09090b` ke `#ffffff` agar chrome app
  terpasang sama dengan permukaan terang aplikasi.
- **`interactive-widget=resizes-content`** ditambahkan ke viewport: keyboard
  Android menyusutkan viewport, jadi footer wizard dan isi sheet tetap
  terlihat saat mengetik — bukan tertimpa keyboard.

## Risiko + rollback

- `:active` skala pada tombol bisa berbenturan dengan transform lain bila ada
  elemen tombol yang di-transform — tidak ditemukan (`active:` utilitas = 0).
  Rollback: hapus blok `.ui-btn-*:active` + gate hover → kembali ke keadaan
  sebelumnya (git revert commit).
- `user-select: none` pada tombol: teks tombol tidak bisa disalin — tidak ada
  kasus di repo ini yang perlu (nomor pengajuan ada di teks konten, bukan
  tombol).
- `interactive-widget=resizes-content` hanya berpengaruh Android Chrome;
  peramban lain mengabaikannya.
