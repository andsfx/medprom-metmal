## Latar

Tabel daftar pengajuan di dashboard admin
(`src/components/admin/AdminDashboardPage.tsx`) hanya merender
`r.submission_number` di kolom "Nomor" (sekitar baris 532-536). Padahal API
daftar `GET /admin/submissions` SUDAH mengirim `b.batch_number`, tipe FE sudah
punya `batch_number` untuk baris daftar, dan Sheet detail SUDAH menampilkan
baris "Nomor Batch". Akibatnya data batch yang dikirim server dibuang UI: staf
tidak bisa mengenali baris pengajuan cetak (batch) dari daftar. Ini cacat
produk nyata (data mati), bukan sekadar soal test.

Perbaikan diminta murni ADITIF: tambahkan baris kecil di bawah
`submission_number` yang merender `r.batch_number` bila ada. Header kolom,
lebar, urutan kolom, dan bagian lain tidak diubah. Baris non-batch
(`batch_number` null/undefined) tidak merender apa pun.

## Rencana

1. Verifikasi dulu (tanpa mengedit): buktikan API daftar mengirim
   `batch_number`, tipe FE siap, dan baca sel tabel yang akan diubah.
2. Tulis test BARU (berkas baru) yang menuntut `batch_number` muncul di DOM
   untuk baris batch dan tidak menambah elemen kosong untuk baris non-batch.
3. Buktikan test bermakna dua arah: MERAH pada kode sebelum perubahan, HIJAU

4. Terapkan perubahan satu sel (aditif), lalu jalankan seluruh gerbang.

   commit dengan Conventional Commits Indonesia. Tanpa push.
