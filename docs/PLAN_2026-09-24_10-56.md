## Temuan T5 (SATU temuan nyata, BELUM diperbaiki, TERHALANG ATURAN)

Pada alur cetak `POST /promo/submit-batch`, checkbox persetujuan ketentuan
**TIDAK dikirim di payload** dan server menuliskan nilai **KONSTANTA** `true`,
TANPA membaca/memvalidasi `body.terms_accepted`.

Bukti (HEAD `d46d988`):

- Checkbox: `src/components/promo/PromoCetakWizard.tsx:910` (`id="cetak-terms"`,
  terikat `termsAccepted`). Validasi klien ada di `:381-384`
  (`if (!termsAccepted) { ... return; }`).
- Payload submit TIDAK memuat `terms_accepted`: `PromoCetakWizard.tsx:389-410`
  (objek `submitBatch({...})` memuat `applicant_type`, `tenant_id`,
  `tenant_name`, `unit_number`, `pic_name`, `pic_phone`, `submission_date`,
  `notes`, `device_fingerprint`, `items`; tidak ada `terms_accepted`).
  Tipe payload `BatchSubmitPayload` (`src/utils/promoApi.ts:397-415`) juga tidak
  punya field itu.
- Server menulis KONSTANTA `true`: `server/src/routes/promo.js:897`
  (`it.air_start_date, it.air_end_date, it.installation_date, true,`) pada
  daftar kolom `:885` (`'...installation_date', 'terms_accepted',...`).
  Handler `submit-batch` tidak pernah membaca `body.terms_accepted`.

Bandingkan alur digital `POST /promo/submit` yang **MEMANG menegakkan**:

- `server/src/routes/promo.js:333` (`const termsAccepted = body.terms_accepted === true;`)
- `server/src/routes/promo.js:355` (`if (!termsAccepted) errors.push('Persetujuan ketentuan wajib dicentang');`)

**Dampak.** Kolom `terms_accepted` pada alur cetak tidak membuktikan
persetujuan; pemanggilan API langsung bisa melewati persetujuan.

**Usulan.** FE mengirim `terms_accepted`, server membaca + menolak 400 bila
bukan `true` + menyimpan nilai sebenarnya.

**KENDALA (dinyatakan tegas).** Menambahkan penegakan di server akan membuat
test LAMA `__tests__/api/promo-batch.test.js` GAGAL, karena fixture `BASE`
(`__tests__/api/promo-batch.test.js:88-98`) TIDAK memuat `terms_accepted`.
Aturan melarang menyunting test lama tanpa izin. Jadi perbaikan T5 **BUTUH
IZIN pemilik** untuk menyesuaikan fixture test lama (atau memilih tidak
menegakkan dan hanya memperbaiki nilai tersimpan).
