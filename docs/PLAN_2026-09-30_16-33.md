## Temuan drift — tiga, semuanya di lapisan judul

### D1. Kelas peran judul kehilangan bobot & transform yang didokumentasikan

DESIGN.md baris 55: *"Bobot **800** untuk judul layar dan judul bagian (kapital
ber-track), 600 untuk judul kartu."*

Kode:

```
.ui-title-screen  { font-weight: 700 }   /* doc: 800 */
.ui-title-section { font-weight: 700 }   /* doc: 800 */
.ui-title-card    { font-weight: 600 }   /* cocok */
```

Ketiganya **tidak** memuat `text-transform` maupun `letter-spacing` sama sekali
— padahal "kapital ber-track" adalah bagian dari definisi dunia ini. Yang benar:
`.ui-title-section` seharusnya memuat `text-transform: uppercase` +
`letter-spacing` agar "BUTUH BANTUAN?" tidak bergantung pada literal huruf
kapital di JSX.

### D2. `.ui-title-section` **didefinisikan tetapi dipakai 0 kali**

Akibatnya 23 `<h2>` di repo tidak punya satu pun rumah; **15** di antaranya
menduplikasi string kelas yang sama persis secara verbatim:

```
text-xl font-extrabold uppercase tracking-wide text-slate-900
```

Ditemukan di `BatchStatusPage`, `PromoCetakWizard` (4×), `PromoLandingPage`
(2×), `PromoUploadWizard` (4×), `SubmissionDetail` (2×), dan lainnya. Ini
**konvensi kedua** di lapisan judul — tepat yang dilarang AGENTS.md ("Ikuti pola
file yang ada; konvensi kedua dilarang"). Nilainya juga kebetulan setara dengan
peran section (20px/700), jadi kelas perannya sudah tersedia dan tinggal dipakai.

### D3. `dark:` adalah kode mati — 192 kemunculan

`192` utilitas `dark:` tersebar di komponen, padahal DESIGN.md menyatakan mode
gelap **belum aktif** dan *"Jangan aktifkan sebelum audit dilakukan."* Tidak ada
kode yang memasang kelas `.dark`, jadi 192 deklarasi ini tidak pernah terpakai —
beban baca di 2.380 baris `AdminDashboardPage` yang harus dipindai manusia.

Proyek ini **sudah** webapp/PWA: `public/manifest.webmanifest` (standalone),
`public/sw.js`, `AppShell` dengan app bar + area menggulir + tab bar bawah, dan

`PromoCetakWizard`, `MySubmissionsPage`, `SubmissionStatusPage`,

dunia "lembar cetak" (tanda potong di 4 sudut, nomor plate, judul lembar 32px,
garis dimensi) adalah metafora **kertas**. Di layar 6 inci, metafora itu memakan
ruang dan terbaca sebagai noise.
