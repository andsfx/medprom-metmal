## Bahaya yang dihindari

1. **`rsync --delete` tanpa pengecualian akan menghapus konfigurasi produksi.**
   `deploy/vps/.env` (rahasia) dan `deploy/vps/Caddyfile` (TLS/routing) tidak ada
   di repo. Keduanya dikecualikan eksplisit; salinan cadangan dibuat ke `/tmp`
   sebelum rsync, lalu diverifikasi masih ada sesudahnya.
2. **`.git` VPS terhapus** oleh rsync (tidak ikut dalam arsip kiriman). Bukan
   kegagalan layanan - aplikasi tidak memakai `.git` - tetapi dipulihkan dari
   lokal agar VPS kembali sesuai runbook; `HEAD` kini `6ebb86d` (= HEAD lokal).
3. **Enam berkas unik VPS** tidak ada di lokal: `scripts/r2-probe.cjs`,
   `server/src/r2.js`, `src/server/`, `backups/`, `Caddyfile.bak-*`,
   `medprom-1.3.0.tar.gz` (0 byte). Sisa eksperimen Cloudflare R2 yang sudah
   digantikan Drive; tidak dirujuk kode mana pun. Dilewatkan, bukan dihapus.

## Urutan deploy yang dijalankan

Mengikuti `deploy/vps/README-DEPLOY.md` langkah 7 (pitfall #10: **stop API dulu**,
jangan `up -d` lalu migrate).

1. Backup pra-deploy: `bash backup.sh` -> `medprom_20260924_172453.sql.gz`.
2. Kirim kode: tar lokal -> `/tmp/medprom-new` -> `rsync -a --delete` dengan
   pengecualian `.env`, `Caddyfile`, `backups/`, `node_modules/`, `*.tar.gz`.
   Verifikasi 8/8 berkas kritis identik dengan HEAD lokal (hash git).
3. `docker compose stop api`.
4. `docker compose run --rm api node scripts/db-migrate.mjs` -> **exit 0**,
   `schema applied (4 tabel)`.
5. `docker compose run --rm api node server/scripts/seed-media-types.mjs` ->
   `0 baru, 4 format disinkronkan, total 14 media type`.
6. `docker compose up -d api`.
7. Verifikasi: `/healthz` ok, `db:true`.

## Query deteksi data warisan (WAJIB dijalankan sebelum migrate berikutnya)

`NOT VALID` melewati scan awal, tetapi UPDATE apa pun pada baris warisan yang
melanggar akan DITOLAK. Jadi periksa dulu; bila ada hasil, perbaiki datanya
sebelum deploy:

```sql
SELECT id, submission_number, source_type, duration_days, quantity
  FROM promo_submissions
 WHERE (source_type = 'none' AND duration_days < 7)
    OR quantity < 1;
```

Hasil pada produksi saat deploy ini: **0 baris** (dua baris warisan keduanya
`source_type` `upload`/`link` dengan durasi 0, yang memang dibebaskan).
