# PLAN 2026-09-16 14:17 — Kredensial akun staf tahap pengembangan

## Tujuan

Menyediakan data login dashboard staf untuk tahap pengembangan: password
seragam `admin123` pada ketiga akun, dan petunjuk akun ditampilkan di halaman
`/login` supaya tim TR tidak perlu menebak.

## Konteks & keputusan

- Password di DB disimpan sebagai hash bcrypt (`$2a$`) — **tidak bisa dibaca
  balik**. Kredensial asli memang tidak dapat diambil; satu-satunya jalan adalah
  menetapkan ulang password lewat `create-admin.mjs --reset`.
- **Disklosur disadari**: situs produksi `medprom-metmal.vercel.app` **publik**,
  jadi menampilkan kredensial di `/login` = siapa pun di internet dapat masuk
  sebagai superadmin. Pengguna memutuskan ini diterima karena masih tahap
  pengembangan, dan meminta petunjuknya ada di halaman login.
- Karena itu panel digerbangi flag opt-out `VITE_PROMO_SHOW_DEV_LOGIN`
  (pola sama dengan `VITE_PROMO_UPLOAD_MODE` yang sudah ada) supaya bisa
  dimatikan **tanpa mengubah kode**.
- Password default `admin123` **tidak** dipindahkan ke server sebagai konstanta
  kebijakan — hanya di `src/constants/devCredentials.ts` (FE) dan diset ke DB via
  skrip sekali jalan.

## Rencana langkah

1. `src/constants/devCredentials.ts` — daftar akun + label peran + flag.
2. Panel petunjuk di `AdminLoginPage` (akun bisa diklik → isi form otomatis).
3. Flag didokumentasikan di `.env.example`.
4. Mount test: flag menyala → terlihat; flag `'0'` → tidak dirender.
5. Reset password produksi ketiga akun ke `admin123`.
6. Verifikasi login sungguhan (positif + negatif) lewat API di VPS.
7. Deploy FE ke Vercel; verifikasi di browser sungguhan.
8. Catat di `CHANGELOG.md` + pitfall `AGENTS.md`.

## Risiko & rollback

| Risiko | Mitigasi |
|---|---|
| **Kredensial publik terbaca siapa pun** (situs live) | Sadar & disetujui pengguna (tahap development). Matikan: `VITE_PROMO_SHOW_DEV_LOGIN='0'` + redeploy. |
| Password lemah (`admin123`) tertinggal sampai go-live | Tercatat sebagai pitfall #13 di `AGENTS.md`; wajib reset sebelum publik. |
| Flag di-*set* di Vercel tetapi tidak berpengaruh | Nilai `VITE_*` di-inline **saat build**; env saja tidak cukup — harus build + deploy ulang. Sudah dicatat di komentar, changelog, dan pitfall. |

**Rollback kode**: `git revert <commit>` lalu redeploy Vercel.
**Rollback password**: `ADMIN_PASSWORD='<kuat>' ... create-admin.mjs <email> "" --reset`.
