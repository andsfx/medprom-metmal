# Redesign "App-Like" + PWA Installable — 2026-09-16 17:31 WIB

## Tujuan

Mengubah medprom-metmal dari terasa *situs dokumen editorial* menjadi terasa
*aplikasi*: shell navigasi tetap, tab bar bawah di mobile, app bar kontekstual,
sheet alih-alih dialog tengah, dan **dapat dipasang** ke home screen (PWA
standalone + offline shell).

Cakupan dipilih pengguna: **full native-feel + installable PWA**, dua sisi
(publik & staf), **sisi tenant diselesaikan lebih dulu**.

## Keputusan yang disepakati

1. **Arah visual bergeser dari "Editorial Kontras" ke "App Produk".** Ini
   konsekuensi pilihan pengguna (opsi 3 mencakup opsi 2). Fraunces **tidak
   dibuang** — turun pangkat jadi aksen display (judul besar, angka), sementara
   Geist mengambil alih seluruh teks antarmuka dengan kerapatan lebih tinggi.
2. **Elevasi dipulihkan, terbatas.** `DESIGN.md` sebelumnya melarang box-shadow
   ("print, bukan material"). Untuk app shell itu tidak bisa dipertahankan:
   app bar sticky, sheet, dan FAB **wajib** punya pemisah saat konten menggulir
   di belakangnya. Shadow dibatasi 3 token dan hanya untuk elemen mengapung —
   kartu statis tetap hairline.
3. **Radius naik** (app terasa lebih lunak dari cetakan): kartu `0.875rem`,
   kontrol `0.625rem`, chip pill penuh.
4. **Tanpa dependensi baru.** Service worker ditulis tangan (bukan
   `vite-plugin-pwa`); ikon PNG dirender memakai Playwright/Chromium yang sudah
   terpasang sebagai devDependency.
5. **Tanpa migrasi DB dan tanpa perubahan API.** Murni lapisan presentasi.
6. **Dark mode**: tetap admin-saja untuk rilis ini. Menyalakannya di publik
   memerlukan audit kontras terpisah; tidak dijanjikan di sini.
7. **Tab bar hanya mobile** (`< sm`). Di desktop navigasi tetap di app bar —
   tab bar bawah pada layar lebar terasa salah, bukan native.

## Temuan yang memicu perbaikan sisipan

Audit kelas CSS (`grep` dipakai-vs-didefinisikan) menemukan **dua kelas dipakai
tetapi tidak pernah didefinisikan** — residu migrasi `sed` pada redesign
sebelumnya:

| Kelas | Dipakai di | Akibat |
|---|---|---|
| `ui-alert-panel` | `AdminDashboardPage.tsx` ×3, `PromoUploadWizard.tsx` ×1 | panel galat tampil **tanpa gaya** — tidak ada latar/garis merah |
| `ui-empty-panel` | `MySubmissionsPage.tsx` ×1 | panel kosong tampil tanpa gaya |

Ini bug nyata yang sedang tayang di produksi: pesan galat wizard kehilangan
penanda visualnya. Diperbaiki sebagai bagian pekerjaan ini.

## Rencana langkah

### Fase 1 — Token & utilitas app
- `src/styles/theme.css`: tambah `--elevation-{bar,card,sheet}`,
  `--radius-{card,control,sheet}` disetel ulang, `--tap-min: 44px`,
  token safe-area.
- `src/styles/base.css`: utilitas `.app-*` (bar, tabbar, sheet, fab, pressable,
  scroll-area). **Perbaiki `ui-alert-panel` + `ui-empty-panel`** — definisikan
  sebagai alias sah, bukan hapus pemakaiannya (diff lebih kecil, 4 callsite aman).

### Fase 2 — Aset PWA
- `public/icon.svg` (sumber), render `icon-192.png`, `icon-512.png`,
  `icon-maskable-512.png`, `apple-touch-icon.png` via
  `scripts/gen-icons.mjs` (Playwright, sekali jalan, hasil di-commit).
- `public/manifest.webmanifest`: `display: standalone`, `theme_color #00918E`,
  `background_color #ffffff`, `lang id`, shortcuts (Ajukan, Riwayat).
- `public/sw.js`: precache shell + strategi *stale-while-revalidate* untuk aset,
  *network-first* untuk `/api/`, fallback offline. Versi cache eksplisit agar
  rilis lama tersapu.
- `index.html`: link manifest, `apple-mobile-web-app-*`, `viewport-fit=cover`.
- `src/main.tsx`: registrasi SW (hanya produksi, `import.meta.env.PROD`).

### Fase 3 — App shell
- `src/components/layout/AppShell.tsx` — kerangka: app bar + slot konten + tab bar.
- `src/components/layout/TopAppBar.tsx` — judul kontekstual, tombol back opsional.
- `src/components/layout/BottomTabBar.tsx` — 3 tab publik, aktif dari `useLocation`.
- `src/components/ui/Sheet.tsx` — bottom sheet mobile / dialog tengah desktop,
  fokus trap + `Escape`.
- `src/App.tsx` — rute publik dibungkus shell; `/login` & `/admin` di luar.

### Fase 4 — Migrasi halaman tenant
`PromoLandingPage`, `PromoUploadWizard`, `MySubmissionsPage`,
`SubmissionStatusPage` — buang header/`min-h-screen` per halaman, pakai shell.

### Fase 5 — Konsol staf
`AdminDashboardPage` app bar sticky + sheet detail; `AdminLoginPage` disesuaikan.

### Fase 6 — Verifikasi
`npm run build`, `npx tsc --noEmit`, `npx vitest run`, mount test untuk komponen
layout baru, lalu **verifikasi visual di browser sungguhan** (mobile viewport +
desktop, cek `display-mode: standalone`, SW terdaftar, manifest valid).

## Sisa pekerjaan

- **Dark mode publik** belum diaktifkan (tetap admin-saja, sesuai rencana).
- **Ikon belum diuji di perangkat nyata** — hanya divalidasi sebagai berkas dan
  lewat manifest. Pemasangan sesungguhnya (Add to Home Screen) sebaiknya
  dicoba di Android/iOS sebelum diumumkan.
- **`CACHE_VERSION` harus dinaikkan** pada setiap rilis berikutnya yang
  mengubah aset shell, jika tidak klien lama akan tertahan di versi lama.
- Sisa item dari handoff sebelumnya yang **tidak** dikerjakan di sini:
  penghapusan baris uji `MP-260916-KJ8Q5B`, `verify-admin-flow.mjs`
  swa-seed, pengaktifan kanal unggah Drive, dan lockdown dev-login (ditunda
  pengguna).

### Dua regresi lanjutan yang ditemukan & diperbaiki
1. **Tombol kembali wizard keluar dari alur.** Langkah 2 & 3 jatuh ke

2. **`data-tabbar` mati** — atribut ditulis tetapi tidak ada CSS yang membaca,
   sehingga wizard menyisakan 60px ruang kosong. Kini `[data-tabbar='off']`
   hanya menyisakan safe area; terverifikasi `0px` vs `60px`.

Keduanya lolos `tsc` — hanya ketahuan lewat telaah kode dan verifikasi visual.
3 test regresi ditambahkan (184 → 187).

## Risiko & rollback

| Risiko | Mitigasi |
|---|---|
| **Service worker menyajikan versi basi** — kesalahan PWA paling umum | Nama cache diberi versi; `skipWaiting` + `clients.claim`; `/api/` **tidak pernah** di-cache-first. Rollback: naikkan versi cache, atau hapus `sw.js` + registrasi lalu deploy (SW lama akan unregister sendiri karena 404 pada pembaruan). |
| Fraunces turun pangkat dianggap kemunduran | Fraunces tetap ada di judul & angka; keputusan pengguna, tercatat di atas. |
| Shadow bertabrakan dengan aturan lama `DESIGN.md` | `DESIGN.md` diperbarui di fase yang sama — dokumen tidak boleh mengklaim aturan yang sudah tidak berlaku. |
| Tab bar menutupi konten / aksi | `padding-bottom` konten = tinggi tab bar + `env(safe-area-inset-bottom)`. |
| Regresi visual admin yang sedang dipakai TR | Admin dikerjakan setelah publik hijau; dark mode admin dipertahankan. |

Rollback UI penuh: `git revert` commit redesign ini lalu redeploy Vercel.
Tidak ada perubahan skema, jadi tidak ada rollback DB.
