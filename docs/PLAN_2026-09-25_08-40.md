# PLAN 2026-09-25 08:40 (WIB) - Alur pemilihan media cetak

## Laporan pemilik

> "workflow nya masih membingungkan, harusnya ketika pilih media cetak,
> langsung menuju pilihan tenant atau non tenant. Bukan langsung ke Step 2"

## Diagnosis

`PromoCetakWizard.tsx` punya tiga langkah: **1 Data Pemohon** (pilih
Tenant/Non-tenant), **2 Pilih Media & Periode**, **3 Ringkasan & Kirim**.
Berbeda dari wizard digital (`PromoUploadWizard.tsx`) yang langkah 1-nya justru
Pilih Media, sehingga pra-pilih media di sana wajar melompat ke langkah 2.

Pada wizard cetak, efek pemuatan katalog memanggil `setStep(2)` ketika query
param `?media=<slug>` cocok dengan katalog cetak:

```ts
if (preselect && rows.some((m) => m.slug === preselect)) {
  setItems([buatBaris(preselect)]);
  setStep(2);            // <-- melompati langkah Data Pemohon
}
```

Akibatnya, membuka `/ajukan-cetak?media=spanduk` (dari kartu cetak di landing)
langsung mendarat di langkah Pilih Media tanpa pemohon ditentukan. Ini keliru:
langkah 1 adalah prasyarat (jenis pemohon menentukan field yang wajib diisi).

## Perbaikan

Hapus `setStep(2)`. Media dari katalog tetap ditandai terpilih lebih awal
(`setItems([buatBaris(preselect)])`), sehingga saat staf menekan "Lanjut ke
Pilih Media" setelah mengisi data pemohon, media itu sudah tercentang.

## Bukti dua arah

Test baru `src/components/promo/__tests__/PromoCetakWizardPreselect.test.tsx`
(3 test):

1. `?media=spanduk` mendarat di langkah Data Pemohon, bukan Pilih Media;
2. media dari katalog tetap tercentang saat langkah Pilih Media dibuka;
3. tanpa `?media=` tetap mulai dari langkah Data Pemohon.

Dijalankan terhadap kode SEBELUM perbaikan: **2 test merah** (bukti menangkap
bug). Sesudah perbaikan: **3 test hijau**.

## Dampak ke skrip verifikasi

`scripts/verify-cetak.mjs` masuk lewat CTA "Ajukan Media Cetak" tanpa `?media=`
(lalu mengisi langkah 1 secara eksplisit), sehingga tidak terpengaruh. Tidak ada
selektor atau teks yang diubah; skrip verifikasi tidak disentuh.

## Catatan

Ini bagian dari alur yang sama dengan `PromoCetakWizard` multi-media; tidak ada
perubahan server, skema, maupun cermin harga.
