# Redesign Airbnb (Rausch) — 2026-11-17

## Tujuan

Mengganti arah desain "Daftar Kerja Seluler" (akromatik, garis rambut, tanpa
bayangan) dengan **dunia Airbnb** mengikuti kontrak
`https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/airbnb/DESIGN.md`:
kanvas putih bersih, satu warna tegangan **Rausch** (`#ff385c`) untuk setiap
CTA primer/orb/hati, tinta `#222222`, satu tier bayangan, dan bahasa bentuk
lunak (pil untuk pencarian/chip, 8px tombol, ~14px kartu, tanpa sudut keras).

Skill yang dipakai: `redesign-existing-projects` (audit + upgrade tanpa merusak
fungsionalitas, bekerja dengan stack yang ada).

## Keputusan

- **Arah Airbnb MENGGANTIKAN arah lama, bukan bertumpuk.** `DESIGN.md`
  ditulis ulang ke kontrak baru; riwayat lama dipertahankan di bagian Riwayat.
  Motif lama (stempel kertas, angka-memimpin ala dokumen kerja) diganti dengan
  hierarki Airbnb: fotografi/tata letak memikul bobot visual, CTA Rausch
  menjadi momen warna tunggal.
- **Font: Inter** (substitusi resmi Airbnb untuk Cereal VF yang berlisensi).
  `--font-display`, `--font-body`, dan `--font-mono` semuanya menunjuk Inter;
  Spline Sans Mono dihapus. Angka tetap `tabular-nums` (fitur font, bukan
  font terpisah) — kolom harga tetap sejajar.
- **Kontras AA tetap ditegakkan.** `#ff385c` hanya 4,0:1 di atas putih, jadi
  nilai token `--action` memakai `#e00b41` (5,7:1, variasi "Rausch Active"
  dari dokumen sumber) dan `--action-strong` memakai `#b30026`. Identitas
  Rausch tetap terbaca; tidak ada teks CTA yang gagal WCAG.
- **Stempel status TIDAK diubah namanya** — warna semantic (ok/rev/no/wait)
  tetap dipertahankan karena itu kebenaran produk, bukan dekorasi. Hanya
  nilai yang diselaraskan ke nada Airbnb (hijau `#008a05`, merah `#c13515`,
  amber `#d97706`, abu `#6a6a6a`).
- **Elevasi: satu tier bayangan** persis dokumen Airbnb
  (`rgba(0,0,0,.02) 0 0 0 1px, rgba(0,0,0,.04) 0 2px 6px, rgba(0,0,0,.1) 0 4px 8px`).
  Dipakai app bar (menggantikan garis bawah), sheet, dan elemen melayang.
  Garis rambut `#ebebeb` tetap untuk pemisah baris daftar.
- **Ramp Tailwind di-remap, bukan dihapus** — pola repo (nama lama
  dipertahankan, nilai baru): `brand-primary` → ramp Rausch;
  `slate`/`stone` → netral Airbnb; `red`/`amber`/`green`/`emerald` → semantic
  baru. Ribuan utilitas lama ikut berubah tanpa menyentuh komponen.
- **Metrik app shell tidak berubah** (bar 56px, tabbar 60px, tap 44px) —
  desain tetap mobile-first; breakpoint Airbnb dipakai untuk typography.

## Rencana

1. Tulis ulang `src/styles/theme.css` (token) + `src/styles/base.css`
   (komponen: tombol, kartu, bar, sheet, chip, calc).
2. Ganti font di `index.html` (Inter; preconnect + preload + swap pola yang
   sama). Naikkan `CACHE_VERSION` service worker (aset shell berubah) + pin
   test.
3. Perbaiki drift komponen: hex keras/slate utilitas yang menyimpang di
   `AdminDashboardPage`, input pencarian → pil, kartu media → radius lunak.
4. Tulis ulang `DESIGN.md` ke kontrak Airbnb.
5. Gate: `tsc --noEmit` + `npm run build` + `npx vitest run --maxWorkers=2`.
6. Smoke visual 6 rute x 2 lebar via Playwright; kontras token utama diukur.
7. Changelog `[Unreleased]` + log dokumen ini.

## Risiko + rollback

- Perubahan terbesar adalah `--action` → Rausch: semua `.ui-btn-primary`
  berubah dari tinta hitam ke rose. Rollback: kembalikan tiga baris token
  `--action*` di `theme.css`.
- `text-brand-primary-*` dipakai sebagai teks tautan kecil — remap ramp
  menjaga kontras (700+ = rose gelap).
- Bayangan app bar baru mungkin membuat bar terasa "mengambang" bagi sebagian
  pemakai; tiernya satu-satunya dan lembut (0.04/0.1 alpha).
