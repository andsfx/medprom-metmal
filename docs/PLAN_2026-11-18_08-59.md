## Perbaikan selama pengerjaan

- Dua contract test layout (`AppShell`, `TopNav`) mengunci IA lama (Ajukan
  sebagai tab). Diperbarui ke IA baru (Beranda/Katalog/Riwayat/Lacak + FAB).
- `gen-icons.mjs` masih memakai latar maskable tosca lama (`#00918E`) dari
  arah yang sudah lewat — diganti `#222222` agar ikon maskable tidak
  berbeda latar dari ikon biasa.
- Test `Stamp` lama mengunci `siap/terpasang/selesai` → `ok`; diperbarui ke
  tujuh nada (D5).

## Risiko & rollback

| Risiko | Mitigasi / rollback |
|---|---|
| FE baru + API lama → Beranda gagal memuat | Deploy API dulu (catatan rilis). Rollback: deploy FE lama. |
| Onboarding mengunci pengguna | `isOnboarded()` fallback `true` saat `localStorage` diblokir; tombol selalu jalan. |
| Angka ringkasan salah | Semua angka server (`GROUP BY`), klien tidak menghitung; test seam mengunci bind status. |
| Katalog "hilang" dari beranda | Tab Katalog + aksi cepat + CTA di beranda kosong. |
| Ikon/cache lama | `CACHE_VERSION` `v16` menyapu cache lama di `activate`. |

## Sisa pekerjaan

- Deploy: API (`/promo/summary`) dulu, lalu frontend (Vercel) — lihat
  `CHANGELOG.md` §Catatan rilis.
- Verifikasi produksi setelah deploy: `node scripts/verify-e2e.mjs`
  (butuh `VERIFY_PASSWORD`), lalu buka `/` di ponsel.
- Layar `katalog.html` prototype punya chip filter kategori; repo memakai
  kelompok per kategori (`CATEGORY_ORDER`) — paritas fungsional, bukan
  paritas bentuk. Bila chip filter diinginkan, itu pekerjaan terpisah.
- `admin.html`/`dashboard.html` prototype hanya acuan visual; konsol staf
  tidak dibangun ulang (kepadatan 4 tab tetap milik repo).
