## Keputusan yang disepakati

1. **Semua sisi-klien.** Katalog sudah termuat penuh dalam satu panggilan
   `fetchMediaTypes`, jadi pencarian + chip menipiskan daftar yang TEREKA —
   pola yang sama dengan filter status di `MySubmissionsPage` (tanpa menyentuh
   server, tanpa permintaan baru).
2. **Kelompok per kategori dipertahankan.** Chip adalah penyaring di atas
   struktur kategori deck yang sudah ada; bukan perombakan tata letak.
3. **B8 memakai tahun berjalan statis** (`new Date().getFullYear()`).
   `/promo/summary` tidak memuat tahun (hanya `GROUP BY status`), dan
   menambah kontrak server demi satu label dinilai tidak sepadan.
4. **A4 menggantikan teks kanal sekarang** ("Cetak, min. 7 hari") dengan
   "Cetak · Tenant Relations" / "Digital · Marcom". Info sewa minimal tetap
   tersedia di hero ("Sewa minimal cetak · 7 hari").
5. **B5/B7 ditunda** (thumbnail+harga di Pengajuan terbaru; aktor+timestamp
   Perlu tindakan): keduanya butuh kontrak server baru (`/mine`, `/summary`)
   dan menunggu keputusan pengguna.

## Rencana langkah (sesuai urutan eksekusi)

1. `PromoLandingPage.tsx`: state `query`+`catFilter`, kotak cari
   (`ui-control`, ikon Search, label sr-only), chip `ui-tag` dengan jumlah per
   kategori + `aria-pressed`, catatan `role="status"`, pesan kosong, dan nama
   handler kanal di baris meta kartu.
2. `BerandaPage.tsx`: label sel "Selesai {tahun}" + hint perpanjangan 7 hari

3. Test: berkas baru `PromoLandingPageFilter.test.tsx` (cari, chip, catatan,
   handler, kosong); dua `it` baru di `BerandaPage.test.tsx` (tahun, hint).
4. Gate: `npm run build` + `npx vitest run` (675 test acuan).
5. `CHANGELOG.md` `[Unreleased]` → `### Ditambahkan`.

## Risiko & rollback

| Risiko | Mitigasi / rollback |
|---|---|
| Teks lama "Cetak, min. 7 hari" dikunci test | Grep dulu; dari pembacaan test landing tidak ada yang mengunci. |
| Chip ambigu dengan judul kategori di aksesibilitas | Nama chip memuat jumlah ("Outdoor 2"), judul bagian polos ("Outdoor") — getByText tidak bentrok. |
| Katalog kosong menampilkan pesan "pencarian" keliru | Pesan generik "Tidak ada media yang cocok." menutup kedua kasus. |
| Rollback | Revert dua komponen + berkas test; tidak ada perubahan server. |
